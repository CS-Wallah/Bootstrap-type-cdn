## Make the project public (recommended):

1. Open Manage and search for 'project visibility'.
2 .Change visibility to Public and save.
3. Load https://gorgeous-taiyaki-d70947.netlify.app/style.css in a private/incognito window.
 If the CSS shows without a login prompt, your <link> tag will work.
